# Lacosta Cleaning Services Website / موقع شركة لاكوستا للتنظيف

This project is a customized frontend web template designed for **Lacosta Cleaning Company** in Egypt. It involves a complete localization and adaptation of an existing HTML/CSS theme, transforming it into a fully responsive, Arabic-language (RTL) website tailored for the local market.

## 📋 Project Overview

The main goal of this project was to customize a generic cleaning service template to fit the specific branding and functional needs of "Lacosta Cleaning". Key modifications include full translation to Arabic, implementation of Right-to-Left (RTL) layout direction, and the integration of local contact methods.

### Key Features
* **Arabic Localization:** Complete translation of all content into Arabic.
* **RTL Support:** Adjusted CSS and HTML structure (`dir="rtl"`) to support Arabic reading direction.
* **Responsive Design:** Fully responsive layout ensuring compatibility across mobile, tablet, and desktop devices (built on Bootstrap).
* **Interactive Elements:** Swiper sliders for testimonials and projects, plus Isotope for gallery filtering.

## 🛠️ Technologies Used
* **HTML5** & **CSS3**
* **Bootstrap 5**
* **JavaScript (jQuery)**

## 🚀 How to Run

1.  Clone or download the repository.
2.  Navigate to the project folder.
3.  Open `index.html` in any modern web browser.

## 🔧 Customization Details

### Translation & Typography
The font family was updated to **'Tajawal'** from Google Fonts to ensure a modern and legible Arabic typography aesthetic.

### Contact Integration
The "Book Now" and contact buttons have been linked directly to the company's WhatsApp number and phone line for immediate conversion:

* **Phone**
* **WhatsApp:** Integrated via `wa.me` links.
